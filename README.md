# MAPEI для iPhone

Ссылка: https://ronineditingwork-bro.github.io/mapei-web/

Откройте в Safari → «Поделиться» → «На экран „Домой“».
Остатки и цены обновляются автоматически каждый час (GitHub Actions, секреты BOMOND_LOGIN / BOMOND_PASSWORD).

Исходники приложения — в приватном репозитории mapei_price; сюда их копирует `web/publish.sh`.
